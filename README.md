# Estado de servicios COYSPU

Monitoreo público de los servicios y sitios de COYSPU con [Upptime](https://upptime.js.org).

Upptime utiliza GitHub Actions para controlar disponibilidad y tiempos de respuesta, GitHub Issues para registrar incidentes y GitHub Pages para publicar el panel.

<!--start: description-->

Este repositorio mantiene el panel de estado de servicios de COYSPU. Los incidentes generados por Upptime se gestionan automáticamente como Issues.
<!--end: description-->

## Panel prototipo anterior

El panel estático original permanece en index.html y usa data/status.json. Upptime publicará su propio panel en la rama gh-pages.
